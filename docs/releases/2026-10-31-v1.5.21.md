# 豆包工坊 v1.5.21 · 云电脑草稿提交精简版

## 更新内容

- 客户端集中为「任务模板 → 云电脑草稿保存 → 批量提交」，默认打开任务模板。
- 保留账号登录、参考附件、草稿恢复、提交记录、停止、原对话取回和必要设置。
- 移除原直接生成、分镜派发、改派、素材库、遮脸、剪映和接口面板入口。
- 删除本机网页版服务与浏览器入口，Windows 安装器不再创建网页快捷方式，升级时清理旧快捷方式。
- 修复繁体豆包页面导入全部失败：同时识别「新工作任務」「新對話」「雲端電腦」「雲電腦」等标签。
- 继续精确核对完整提示词、附件、原生草稿编号和账号归属，不因语言兼容放宽内容核对；保留付费选项拦截。
- 旧直接生成任务不再自动执行或重新派发；已有用户数据保留。

## 安装与升级

下载本 Release 对应平台与架构的附件：Windows x64 使用 `DoubaoWorkshop-1.5.21-Setup.exe`；Apple 芯片 Mac 使用 `DoubaoWorkshop-1.5.21-mac-arm64.dmg`。两个平台分别提供 SHA-256 校验文件。

升级前退出客户端，再替换应用。macOS 用户数据继续沿用 `~/Library/Application Support/无限豆包`；请保留该目录。已有模板、附件和待导入记录无需重新添加。

Mac 安装包采用临时签名，未经过 Apple Developer ID 签名和公证。请遵循系统正常安全提示，项目不会修改系统安全设置。

Windows x64 包由 Windows 原生环境构建并执行安装与客户端验收；Apple 芯片 Mac 包由 Mac 本机构建并验收。Intel Mac 暂无本版本安装附件。GitHub 发布不代表原内网更新服务已同步。
